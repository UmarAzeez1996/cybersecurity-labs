# Password Strength Checker

A simple password strength checker built using HTML, CSS, and JavaScript.

## Features
- Detects weak passwords
- Detects medium passwords
- Detects strong passwords
- Responsive modern UI

## Technologies Used
- HTML
- CSS
- JavaScript

## Password Rules
Strong passwords should contain:
- Uppercase letters
- Numbers
- Special characters
